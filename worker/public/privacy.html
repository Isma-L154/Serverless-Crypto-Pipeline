Privacy Notice

Last updated 25 August 2026

This is a personal, non-commercial project that displays public cryptocurrency market data. It has no accounts, no sign-up and no contact form, so there is very little to tell — but "very little" is not "nothing", and the parts that are true are set out below.

The short version

  • No cookies. None are set, by this site or anyone else.
  • No accounts. There is nothing to sign up for.
  • Nothing you type is collected, because there is nowhere to type.
  • Nothing is sold, shared or used for advertising.
  • No tracking across other websites.

What is processed

Your IP address

Every request to this site carries your IP address, as every request on the web does. It is used for two things:

  • Rate limiting. The data endpoints are capped per visitor so that one automated client cannot exhaust the free database allowance and take the dashboard offline for everyone. Your address is used to count your requests and is not stored by this project.
  • Serving the page. Cloudflare, which hosts this site, keeps standard request logs under its own retention policy.

An IP address can identify you indirectly, so it is treated as personal data here even though nothing is kept.

Visit measurement

This site uses Cloudflare Web Analytics, which reports aggregate page views. It sets no cookies, does not fingerprint your browser and does not follow you to other sites.

Third parties

Only one third party is involved in loading this page, and it is the company already serving it:

WhoWhyWhat they receive
Cloudflare Hosting, rate limiting, analytics Your IP address and request details
CoinGecko Source of the price data Nothing about you. This site fetches prices on a schedule from its own server; your browser never contacts CoinGecko unless you click the link in the footer.

Fonts are served from this domain. The typefaces were originally loaded from Google Fonts, which meant every visitor's IP address reached Google before a single price was drawn. They are now hosted here, so rendering this page involves no request to Google at all.

Data this site does store

The database holds cryptocurrency prices and nothing else — coin, price, market capitalisation, volume, and the time each was recorded. There is no column anywhere that describes a person. Recent prices are kept for about two days; a daily summary is kept indefinitely.

Your rights

Data protection law gives you rights to access, correct and erase personal data held about you. In practice there is nothing here to act on: this project stores no personal data, so there is no record to retrieve or delete. For the request logs and analytics described above, those are held by Cloudflare under their privacy policy.

Children

This site is not directed at children and collects nothing from anyone, regardless of age.

Changes

If what the site does changes, this page changes with it and the date at the top is updated. The full history of this page is public in the project's source repository, so any edit can be inspected.

Contact

Questions about this notice can be raised as an issue on the project repository.
